Files:

- style.css: responsive styling
- script.js: search and category filters
- privacy.html: starter privacy page
- disclosure.html: affiliate disclosure page

HOW TO PUBLISH WITH GITHUB PAGES:
1. Open your GitHub repository named smart-tool-picks.
2. Click Add file > Upload files.
3. Upload all five files from this folder (not the folder itself).
4. Click Commit changes.
5. Open repository Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Select branch main and folder /(root), then Save.
8. Wait a few minutes; GitHub will show your site URL in Settings > Pages.

BEFORE PUBLIC LAUNCH:
- Replace hello@smarttoolpicks.com with an email address you control.
- Review all page text and tool descriptions.
- Apply to affiliate programs and replace ordinary provider links only after approval.
- Add any legally required business, privacy, cookie and advertising disclosures for your audience.

This is a static starter website. It does not include a backend, newsletter signup database, analytics, or affiliate tracking yet.
